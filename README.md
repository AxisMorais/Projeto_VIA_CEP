# Projeto_VIA_CEP

Construção de uma página no qual o usuário informa o número de um CEP retornando os dados referentes aquele CEP, como logradouro, bairro, cidade. 
Para a Consulta dos dados foi utilizado a API Via CEP.


# Tecnologias utilizadas:
#### • Front End:  
> HTML5, JavaScript, CSS3.  

#### • Back End:  
> Java 21, Spring Boot, Spring Web, Spring Data JPA, Hibernate, Jackson, RestClient, Lombok,Thymeleaf, Spring Boot DevTools, Maven

• API Externa:
> ViaCEP

• Banco de dados:    
> MySQL 8.0
